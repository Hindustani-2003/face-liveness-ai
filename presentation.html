SYSTEM COMPONENT ARCHITECTURE

End-to-End Data Pipeline Flow:

  1. Browser Client Layer (React 19 + Vite): Captures video stream, executes WebGL hardware-accelerated face-api.js inference, extracts 68 facial landmarks & 128-D vector locally.
  2. API Middleware Layer (tRPC + Express): Receives 128-D vector payload over HTTPS, validates input schemas via Zod, manages JWT session cookies.
  3. Cloud Storage Layer (Aiven MySQL 8.0): Executes 1:1 Euclidean distance vector matching (Threshold < 0.60) over encrypted SSL connections.
